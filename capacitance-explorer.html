How C depends on each variable

Key ideas

  • C ∝ A. Only the overlap matters. Slide the plate up and the charge can only gather where the plates face each other.
  • C ∝ 1/d. Halving the gap doubles C. A graph of C against 1/d is a straight line through the origin.
  • Dielectrics raise C by a factor εr. The molecules polarise, and the charges induced on the slab's surfaces partly cancel the field. For the same charge Q the p.d. V is smaller, so C = Q/V is larger.
  • Part-filled gap. With the slab part-way in, the two regions act like capacitors in parallel, so their capacitances add.
  • Values of εr shown are typical. Real values vary with temperature, frequency and purity, especially for the titanates.
