Definition

The half-life of a radioactive isotope is the time taken for half of the undecayed nuclei in a sample to decay.

It is also the time taken for the activity (or the count rate) of a sample to fall to half of its starting value.

Key ideas

  • Decay is random. You cannot predict which nucleus will decay next, or when.
  • Activity is the number of nuclei that decay each second, measured in becquerels. 1 Bq = 1 decay per second.
  • A Geiger–Müller tube and counter measure the count rate, in counts per second or counts per minute.
  • Background radiation adds to every reading. Subtract it before you look for halving.
  • The activity of a source decreases over time, because fewer undecayed nuclei are left.

Method for a table of count rates

  1. If a background count rate is given, subtract it from every reading.
  2. Pick a corrected count rate in the table, usually the first one.
  3. Find the time when the corrected count rate has fallen to half of that value.
  4. Half-life = the time between those two readings. Check it with another pair if you can.

Counting half-lives

If the count rate halves several times, count the halvings. For 1600 → 800 → 400 → 200 in 12 hours, that is 3 half-lives, so the half-life is 12 ÷ 3 = 4 hours.

Real readings jump about because decay is random. That is why plotting a graph and drawing a smooth curve usually gives a better value.

Half-life from one reading

Drag the slider to choose any starting count rate. The half-life comes out the same wherever you start.

Steps

  1. Choose a count rate on the vertical axis. The first value on the curve is the easiest.
  2. Draw a line across to the curve, then down to the time axis. Read the time t₁.
  3. Halve the count rate. Draw across and down again. Read the time t₂.
  4. Half-life = t₂ − t₁

Half-life from several readings

Keep halving the count rate and read the time each time. Then take the mean of the half-life values.

Readings from the curve

Why take several readings?

  • Each reading from a graph has a small reading error. Averaging several values makes the result more reliable.
  • Measured points scatter because decay is random. Draw a smooth curve of best fit through them and take your readings from the curve, not from single points.
  • Each time interval should be about the same. If one is very different, check that reading again.

A quick shortcut

The mean of the intervals is the same as the total time divided by the number of half-lives. For 960 → 120 counts/min, that is 3 halvings. If it takes 7.2 hours, the half-life is 7.2 ÷ 3 = 2.4 hours.
